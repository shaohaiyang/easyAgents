# EasyAgents Phase 1.5 - SQLite Persistence, Context Management, and New Tools

> Date: 2026-07-30
>
> Status: Draft
>
> Depends on: MVP (Phase 1) - complete

## 1. Overview

Phase 1.5 extends the EasyAgents SDK with four capabilities:

1. **SQLite persistence** - Dual-backend session storage (in-memory + SQLite)
2. **http_request tool** - HTTP client tool for calling external APIs
3. **write_file tool** - File writing tool for saving agent outputs
4. **Context management** - Automatic threshold-based message compression using LLM summarization

### 1.1 Design Principles

- **Backward compatible** - Existing `SessionManager()` with no args behaves identically to MVP
- **Incremental evolution** - New modules added alongside existing code; no breaking changes
- **Explicit over implicit** - ContextManager is called explicitly by the developer, not hidden in SessionManager
- **Sync API preserved** - SessionStore uses sync methods; SQLite local I/O is fast enough to not block

### 1.2 Architecture

```
┌─────────────────────────────────────────────────────┐
│                 Public API (__init__.py)              │
├──────────────┬──────────────┬───────────────────────┤
│  Persistence │   Context    │      Tools            │
```

## 3. SessionStore & SQLite Persistence

### 3.1 SessionStore Abstract Base Class

```python
# persistence/base.py
from abc import ABC, abstractmethod
from pydantic_ai import ModelMessage
from easyagents.core.session import Session


class SessionStore(ABC):
    """Abstract base class for session storage backends."""

    @abstractmethod
    def create(self) -> Session:
        """Create a new session with a generated conversation_id."""

    @abstractmethod
    def get(self, conversation_id: str) -> Session | None:
        """Retrieve a session by conversation_id. Returns None if not found."""

    @abstractmethod
    def save_messages(self, conversation_id: str, messages: list[ModelMessage]) -> None:
        """Save messages for a session. Overwrites existing messages."""

    @abstractmethod
    def delete(self, conversation_id: str) -> None:
        """Delete a session and all its messages."""

    @abstractmethod
    def list_sessions(self) -> list[str]:
        """List all conversation_ids."""
```

### 3.2 InMemorySessionStore

Refactored from the MVP `SessionManager` logic. Uses a `dict[str, Session]` internally. Adds `delete()` and `list_sessions()` methods not present in the MVP.

### 3.3 SQLiteSessionStore

```python
# persistence/sqlite.py
class SQLiteSessionStore(SessionStore):
    def __init__(self, db_path: str = "easyagents.db"):
        """Initialize SQLite session store.

        Args:
            db_path: Path to SQLite database file. Use ":memory:" for in-memory DB.
        """
```

**SQLite Schema:**

```sql
CREATE TABLE IF NOT EXISTS sessions (
    conversation_id TEXT PRIMARY KEY,
    created_at      TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at      TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS messages (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    conversation_id TEXT NOT NULL,
    seq             INTEGER NOT NULL,
    message_data    TEXT NOT NULL,
    FOREIGN KEY (conversation_id) REFERENCES sessions(conversation_id)
);

CREATE INDEX IF NOT EXISTS idx_messages_conversation
    ON messages(conversation_id);
```

**Message serialization:** Messages are serialized to JSON using Pydantic's `TypeAdapter(list[ModelMessage])`. On `save_messages()`, existing messages for the session are deleted and new ones inserted (delete-then-insert strategy). On `get()`, messages are deserialized from JSON back to `ModelMessage` objects.

**Connection management:** Each method call opens a connection via `sqlite3.connect(db_path)` (or uses a persistent connection). The `__init__` creates tables if they don't exist.

### 3.4 SessionManager Facade

```python
# core/session.py (modified)
class SessionManager:
    def __init__(self, store: SessionStore | None = None):
        self._store = store or InMemorySessionStore()

    def create(self) -> Session:
        return self._store.create()

    def get(self, conversation_id: str) -> Session | None:
        return self._store.get(conversation_id)

    def save_messages(self, conversation_id: str, messages: list[ModelMessage]) -> None:
        if self._store.get(conversation_id) is None:
            raise EasyAgentsError(f"Session '{conversation_id}' not found")
        self._store.save_messages(conversation_id, messages)

    def delete(self, conversation_id: str) -> None:
        self._store.delete(conversation_id)

    def list_sessions(self) -> list[str]:
        return self._store.list_sessions()
```

**Backward compatibility:** `SessionManager()` with no arguments creates an `InMemorySessionStore`, behaving identically to the MVP. To use SQLite: `SessionManager(SQLiteSessionStore("my.db"))`.

**Circular import avoidance:** `SessionStore` (in `persistence/base.py`) references `Session` (in `core/session.py`) for type hints, while `SessionManager` (in `core/session.py`) references `SessionStore`. To avoid circular imports, `persistence/base.py` uses `from __future__ import annotations` so the `Session` type is evaluated lazily. No runtime import of `Session` is needed in the ABC.

## 4. ContextManager

### 4.1 Overview

ContextManager provides automatic message compression when token count exceeds a configurable threshold. It uses an LLM to summarize old messages while preserving recent ones.

### 4.2 API

```python
# context/manager.py
class ContextManager:
    def __init__(
        self,
        model: str = "openai:gpt-4o",
        max_tokens: int = 8000,
        keep_recent: int = 4,
        compression_prompt: str = "",
    ):
        """Initialize context manager.

        Args:
            model: Model string for summarization agent (e.g. "openai:gpt-4o").
            max_tokens: Token threshold. Messages compressed when exceeded.
            keep_recent: Number of recent messages to preserve uncompressed.
            compression_prompt: Custom system prompt for summarization agent.
                If empty, uses a default prompt.
        """

    async def compress_if_needed(
        self, messages: list[ModelMessage]
    ) -> list[ModelMessage]:
        """Check token count, compress if threshold exceeded.

        If token count <= max_tokens, returns messages unchanged.
        Otherwise, summarizes old messages and returns [summary] + recent.
        """
```

### 4.3 Compression Flow

```
compress_if_needed(messages)
  |
  +-- count_tokens(messages) <= max_tokens?
  |     YES -> return messages (no compression)
  |
  +-- NO:
      +-- Split messages:
      |     old_messages = messages[:-keep_recent]
      |     recent_messages = messages[-keep_recent:]
      +-- Create temporary Pydantic AI Agent:
      |     instructions = compression_prompt or default
      |     model = self.model
      +-- Run agent with old_messages as input
      +-- Construct summary message (ModelRequest with SystemPart)
      +-- Return [summary_message] + recent_messages
```

### 4.4 Token Counting

Uses a simple heuristic: `len(str(messages)) // 4` as a rough token estimate. This avoids adding `tiktoken` as a dependency. The estimate is conservative (tends to overcount), which is acceptable for threshold checking. Future phases can replace with precise tokenization.

### 4.5 Summarization Agent

A temporary `pydantic_ai.Agent` is created internally (not registered in `AgentRegistry`). It uses:
- `instructions`: A default prompt like "Summarize the following conversation concisely, preserving key facts, decisions, and context."
- `model`: The model specified in `ContextManager.__init__`

The agent runs with the old messages as user input and returns a text summary.

### 4.6 Error Handling

- LLM call failure raises `ContextCompressionError` with context (message count, token count, error details)
- No silent degradation - if compression fails, the caller knows and can decide how to handle it

### 4.7 Usage Pattern

```python
from easyagents import ContextManager, SessionManager, SQLiteSessionStore

store = SQLiteSessionStore("conversations.db")
sessions = SessionManager(store)
ctx_mgr = ContextManager(model="openai:gpt-4o", max_tokens=8000)

# After agent run
result = await agent.run("调研蓝牙耳机", message_history=session.messages)

messages = result.all_messages()
messages = await ctx_mgr.compress_if_needed(messages)  # Compress if needed
sessions.save_messages(session.conversation_id, messages)
```

## 5. Built-in Tools

### 5.1 http_request

```python
# tools/builtin/http_request.py
async def http_request(
    url: str,
    method: str = "GET",
    headers: dict[str, str] | None = None,
    body: str | None = None,
    timeout: int = 30,
) -> dict[str, Any]:
    """Make an HTTP request and return the response.

    Args:
        url: Target URL.
        method: HTTP method (GET, POST, PUT, DELETE, etc.).
        headers: Optional request headers.
        body: Optional request body (for POST/PUT).
        timeout: Request timeout in seconds (default 30).

    Returns:
        {"status": int, "headers": dict, "body": str}
        On network error: {"status": 0, "error": str}
    """
```

**Implementation:** Uses `httpx.AsyncClient`. Network errors (timeout, connection refused, DNS failure) return `{"status": 0, "error": "..."}` instead of raising. This follows the same error strategy as `web_search` - let the agent adapt to failures.

**New dependency:** `httpx>=0.27` added to `pyproject.toml`.

### 5.2 write_file

```python
# tools/builtin/write_file.py
async def write_file(
    path: str,
    content: str,
    append: bool = False,
) -> dict[str, Any]:
    """Write content to a local file.

    Args:
        path: File path (relative to work directory or absolute).
        content: Content to write.
        append: If True, append to file. If False, overwrite (default).

    Returns:
        {"path": str, "bytes_written": int}
    """
```

**Implementation:** Uses `asyncio.to_thread` to wrap synchronous file I/O, avoiding event loop blocking.

**Path safety:** Rejects paths containing `..` (path traversal). Files must be within the current working directory or a configured base directory. Returns `{"path": "", "error": "Path traversal denied"}` on violation.

**No new dependencies.**

### 5.3 Registration

Tools are registered manually, same as `web_search`:

```python
from easyagents import ToolRegistry, http_request, write_file, web_search

tools = ToolRegistry()
tools.register("web_search", web_search)
tools.register("http_request", http_request)
tools.register("write_file", write_file)
```

## 10. Error Handling

### 10.1 Error Strategy

| Error Source | Strategy |
|--------------|----------|
| SQLite operation failure | Raise `SessionStoreError` with context |
| Session not found in save_messages | Raise `EasyAgentsError` (existing behavior) |
| Context compression LLM failure | Raise `ContextCompressionError` |
| http_request network failure | Return error dict, let agent adapt |
| write_file path traversal | Return error dict, let agent adapt |
| write_file permission denied | Return error dict, let agent adapt |

### 10.2 No Silent Failures

Consistent with MVP error strategy. Every error either:
1. Raises an exception (store failures, compression failures)
2. Returns a degraded result with error info (tool failures: http_request, write_file)

## 11. Migration Guide

### For Existing MVP Users

No changes required. The following code continues to work identically:

```python
from easyagents import SessionManager

sessions = SessionManager()  # Still uses InMemorySessionStore
session = sessions.create()
sessions.save_messages(session.conversation_id, messages)
```

### Upgrading to SQLite

```python
from easyagents import SessionManager, SQLiteSessionStore

sessions = SessionManager(SQLiteSessionStore("conversations.db"))
# Same API, now persisted to disk
```

### Adding Context Management

```python
from easyagents import ContextManager

ctx = ContextManager(model="openai:gpt-4o", max_tokens=8000)

# After agent run, before saving
messages = await ctx.compress_if_needed(messages)
sessions.save_messages(session.conversation_id, messages)
```

### Using New Tools

```python
from easyagents import ToolRegistry, http_request, write_file

tools = ToolRegistry()
```
